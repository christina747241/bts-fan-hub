# BTS Fan Hub

A BTS fan website developed as a full-stack web development project.

## Features

- BTS members section with search and category filters
- Discography with favorite albums
- News section with search and sorting
- User registration and login
- User profile
- Community signup form
- News comments
- Events and booking management
- Admin panel for managing news and viewing bookings
- Light and dark themes

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO
- Docker

## Requirements

- PHP with PDO MySQL support
- MySQL
- Environment variables for database configuration

## Setup

1. Copy `.env.example` to `.env` in the local environment.
2. Configure the database connection variables.
3. Configure a PHP server and MySQL database.
4. Start the application using your local development environment.

## Security

- Passwords are hashed using PHP password hashing functions.
- Database queries use prepared statements.
- Protected actions use session-based authorization and CSRF tokens.
- Database credentials should be provided through environment variables.
